# vbm-json has moved

**This repository is archived (read-only).** The library now lives in the VBM family repository:

> **https://github.com/witt3rd/vbm/tree/main/lib/vbm-json**

* **History:** all of this repository's history is in the family repository (`git log lib/vbm-json` and `git blame` follow it).
* **Releases:** the releases made here (`v0.1.0` ) stay here with their signatures. Each is released again there as `vbm-json/<version>` (signed by the same key; its `tree_sha256` is identical). New releases are tagged `vbm-json/vX.Y.Z` in the family repository.
* **Issues and changes:** open them in the family repository.
* **Pins:** a pin at a tag of this repository keeps verifying (the files are unchanged); re-point it with `land-pin vendor vbm-json https://github.com/witt3rd/vbm vbm-json/<version>` and the vendored files come out byte for byte as they were.
